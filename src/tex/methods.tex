\subsection{Astrophysical Mixture Models} \label{sec:astromodels} 

We make use of the Basis-Spline (B-Spline) models from \cite{2022arXiv221012834E} (See Appendix A in \brucepaper{} for a mathematical description of B-Splines), though with minor differences in prior choices and numbers of basis functions. We utilize the same smoothing prior as \brucepaper{} to penalize large differences between neighboring coefficients in order to mitigate overfitting. Our coefficient and smoothing priors have the same form as equations B4 and B5 in \brucepaper{}, though we fix the value of the smoothing prior scale $\tau_\lambda$ for each B-Spline model. We found that $\tau_\lambda$ consistently railed against boundaries set by the minimum required effective sample size in single-event Monte Carlo integrals, wherein the minimum effective sample size was the main driver of smoothness. We therefore opted to fix $\tau_\lambda$ for each population distribution to reasonable values that produced results consistent with other non-parametric results like \citet{2022ApJ...924..101E}, \brucepaper{}, and \citet{10.48550/arXiv.2302.07289}. We plan to address this issue in a future work by exploring different coefficient and smoothing prior specifications, such as locally adaptive smoothing priors. 

Given the recent evidence for peaks \citep{2019ApJ...882L..24A, 2021ApJ...913L...7A, 2023PhRvX..13a1048A, 2022ApJ...928..155T,2022ApJ...924..101E, 2022arXiv221012834E,10.48550/arXiv.2302.07289} in the BBH primary mass spectrum at $10 M_{\odot}$, $35 M_{\odot}$, and suggestions of a potential feature at $\sim20 M_{\odot}$, we construct two mixture models designed to identify a peak in primary mass and compare its mass ratio and spin properties to the rest of the mass spectrum. The models are summarized below and a detailed description of each including prior choices can be found in Appendix \ref{sec:model-descrip}.

\begin{itemize}
    \item {\bfseries{\scshape Isolated Peak}} (See Appendix \ref{sec:isopeak}) This model is a mixture between a log-Normal and a log-B-Spline distribution in primary mass. Each mass component is assigned unique B-Spline spin and log-B-Spline mass ratio distributions. This model is similar to the \textsc{Multi Spin} model in \cite{2021ApJ...913L...7A}, though we replace all of the simple parametric models (excluding the primary mass peak) with fully data-driven B-Splines. This allows us to remove any \textit{a-priori} assumptions about shape in all distributions except for the log-Normal mass distribution, thereby minimizing model misspecifiation bias in our results.
\end{itemize} 

\begin{itemize}
    \item {\bfseries{\scshape Peak+Continuum:Spin}} (See Appendix \ref{sec:peak+cont}) Based on the results of the \base{} model (discussed in Section \ref{sec:results}), we construct the \comp{} model to analyze how consistent the spin properties of systems outside of the primary mass peak are to those in the peak. We use the same model description as the \base{} except the spin distribution of the events in the log-B-Spline mass component is now a mixture between two distributions. The first distribution is required \textit{at minimum} to be informed by the events in the peak while the other will only be informed by events outside of the peak. The former will be guided by the spin properties of the peak so the mixing fraction between the two distributions will indicate the fraction of systems outside of the peak that are consistent with the peak's spin properties. 
\end{itemize}

Like the \textsc{Multi Spin} model, the \base{} and \comp{} allows for multiple \textit{subpopulations} of BBH systems with distinct mass and spin distributions. We acknowledge that "subpopulation" can be a loaded term, but for convenience, we will use "subpopulation" in the same way as \citet{2021ApJ...913L...7A}, i.e. to indicate a subset of BBH systems in the catalog with one or more parameter distributions \textit{allowed} to differ from the rest of the catalog. When discussing the results of the \base{}, we will refer to the subpopulation that contains the primary mass peak as $\textsc{PopA}$ and the subpopulation that does not contain the peak as $\textsc{PopB}$. When discussing the \comp{}, we will distinguish the subpopulations based on their spin distributions and therefore we will refer to the \textit{spin} subpopulation that is informed by (but not limited to) the events in the primary mass peak as \textsc{SpinPopA} and the spin subpopulation that excludes the peak as \textsc{SpinPopB}. 

In both of our model prescriptions, the spin magnitude and tilt distributions of each binary component are assumed to be independently and identically distributed (IID); i.e. both binary components have spins drawn from the same (inferred) distribution. We do not infer the mininum and maximum BBH primary mass and instead truncate all the mass distributions below $m_\text{min} = 5.0\msun$ and above $m_\text{max} = 100\msun$. We assume the same redshift distribution for all subpopulations and model it as a modulated power law as in \brucepaper{}:

\begin{equation}
    p(z|\Lambda_z) = \frac{dV}{dz} (1+z)^{\lambda - 1} \exp \mathcal{B}(\text{log}z).
\end{equation} 

Within the \textsc{NumPyro} \citep{1810.09538,1912.11554} probabilistic programming language, we use the \texttt{NUTS} \citep{1111.4246} sampler to perform our parameter estimation. All the models and formalism used in our analysis are available in the \href{https://github.com/FarrOutLab/GWInferno}{GWInferno} python library, along with the code and data to reproduce this study in this GitHub \href{https://github.com/jaxeng/CosmicCousins}{repository}. 



\subsection{Dataset} \label{sec:dataset} 

With these models and framework in hand, we infer the mass, spin and redshift distributions with the most recent LVK catalog of gravitational wave observations, GWTC-3 \citep{2021arXiv211103606T}. We perform the same BBH threshold cuts on the catalog done by the LVK's accompanying population analysis \othreea{}. For the remaining 69 BBH mergers, we follow what was done in \citet{2021arXiv211103606T}: for events included in GWTC-1 \citep{2019ApJ...882L..24A}, we use the published samples that equally weight samples from analyses with the \textsc{IMRPhenomPv2} \citep{1308.3271} and \textsc{SEOBNRv3} \citep{1307.6232,1311.2544} waveforms; for the events from GWTC-2 \citep{2021ApJ...913L...7A}, we use samples that equally weight all available analyses using higher-order mode waveforms (\textsc{PrecessingIMRPHM}); finally, for new events reported in GWTC-2.1 and GWTC-3 \citep{2021arXiv211103606T,2108.01045}, we use combined samples, equally weighted, from analyses with the \textsc{IMRPhenomXPHM} \citep{2004.06503} and the \textsc{SEOBNRv4PHM} \citep{2004.09442} waveform models.
